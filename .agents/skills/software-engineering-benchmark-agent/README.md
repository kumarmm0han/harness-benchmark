# Software Engineering Benchmark Agent

A harness-neutral engineering workflow using fixed `PRINCIPLES.md`, `REQUIREMENTS.md`, a starter repository, and model settings.

Each run creates `ARCHITECTURE.md`, `TECHNICAL_DESIGN.md`, `TASKS.md`, implementation, tests, and `VERIFICATION.md`.

Use `examples/benchmark-prompt.md` to invoke the workflow. Verification records requirement coverage, actual build/test outcomes, assumptions, and known limitations.
